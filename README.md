# Desarrollo de Aplicaciones y Servicios Virtuales
## Objetivo: 
Aplicar de forma integrada el flujo de preparación, versionamiento y colaboración de un proyecto.
## Tecnologías utilizadas
Visual Studio Code, entorno virtual, dependencias, Git y GitHub.
## Pasos de instalación 
- Crear el entorno virtual
- Instalar python
- Instalar las bibliotecas en python correspondientes
- Agregar las dependencias desde la terminal
## Dependencias
pip install requests
pip install python-dotenv
pip list
pip freeze > requirements.txt
